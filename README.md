# House Price Prediction

A Machine Learning project that predicts house prices using regression algorithms.

## Models Used

- Linear Regression
- Random Forest Regressor

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Project Features

- Data cleaning
- Feature selection
- Train-test split
- Feature scaling
- Log transformation of house prices
- Model training
- Model evaluation using MSE and R²
- House price prediction using Streamlit
